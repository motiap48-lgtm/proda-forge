### Чего НЕТ по сравнению с 1С:ERP

```text
1С:ERP                              EVA (наше приложение)
────────────────────────────────────────────────────────────
Управление закупками (полный цикл)   ✗ Только заявки на закупку
Управление продажами                 ✗ Нет
Управление финансами / Бюджетирование ✗ Заглушка "Финансы"
Себестоимость / Калькуляция           ✗ Нет
Управление качеством (ОТК)           ✗ Только учет брака при выполнении
Управление ТОиР (обслуживание)       ✗ Даты обслуживания оборудования есть, логики нет
Управление персоналом / Кадры         ~ Операторы/бригады, но не полный HR
Планирование по узким местам          ~ Ганта есть, но нет автопланирования
Управление логистикой / Доставка      ✗ Нет
CRM / Управление взаимоотношениями    ✗ Только справочник заказчиков
Документооборот                       ✗ Нет
Межцеховое планирование               ~ Частично через техмаршруты
Управление несколькими предприятиями   ✗ Нет
Интеграции (ЭДО, банк-клиент)        ✗ Нет
```

## План доработки по очередям

### Очередь 1 — Критичные модули (8-12 недель)

**1. Управление качеством (ОТК)**
- Акты несоответствий, контрольные операции в техмаршрутах
- Статусы: годен / брак / доработка, привязка к операциям
- Реализация: новые таблицы `quality_inspections`, `defect_types`, расширение `production_order_operations`
- **Срок: 3 недели**

**2. Управление ТОиР (техобслуживание и ремонт)**
- Плановое ТО по оборудованию, регистрация простоев
- Заявки на ремонт, история обслуживания, уведомления
- Реализация: таблицы `maintenance_orders`, `equipment_downtimes`, триггеры уведомлений
- **Срок: 3 недели**

**3. Расширение складского учета**
- Приходные ордера, инвентаризация, перемещение между складами
- Партионный учет, серийные номера
- Реализация: таблицы `warehouse_receipts`, `stock_movements`, `inventory_counts`
- **Срок: 3-4 недели**

**4. Автоматическое планирование производства**
- Планирование по узким местам, автоназначение на участки
- Расчет загрузки рабочих центров, оптимизация очереди
- Реализация: edge function с алгоритмом планирования, таблица `planning_runs`
- **Срок: 2-3 недели**

### Очередь 2 — Важные модули (10-14 недель)

**5. Управление закупками (полный цикл)**
- Заказы поставщикам, справочник поставщиков, приемка
- Контроль сроков поставки, связь с MRP
- Реализация: таблицы `suppliers`, `purchase_orders`, `purchase_order_lines`, `goods_receipts`
- **Срок: 4 недели**

**6. Калькуляция себестоимости**
- Плановая/фактическая себестоимость по заказам
- Учет материалов, трудозатрат, накладных расходов
- Реализация: таблицы `cost_items`, `order_costs`, edge function расчета
- **Срок: 3 недели**

**7. Управление продажами (базовое)**
- Заказы покупателей, связь с производственными заказами
- Статусы отгрузки, план отгрузок
- Реализация: таблицы `sales_orders`, `sales_order_lines`, `shipments`
- **Срок: 3-4 недели**

**8. Расширенная аналитика и BI**
- KPI производства (OEE, OTIF, Lead Time)
- Настраиваемые дашборды, экспорт в PDF
- Реализация: recharts + новые агрегирующие запросы
- **Срок: 2 недели**

### Очередь 3 — Дополнительные модули (8-12 недель)

**9. Документооборот**
- Шаблоны документов, согласования, электронные подписи
- Привязка документов к заказам/операциям
- **Срок: 3 недели**

**10. Управление персоналом (расширенное)**
- Штатное расписание, отпуска, больничные (полный цикл)
- Квалификации, допуски, аттестации
- **Срок: 3 недели**

**11. Интеграции**
- API для внешних систем (REST), вебхуки
- Импорт/экспорт 1С (обмен данными)
- Интеграция с ЭДО (Диадок/СБИС)
- **Срок: 4 недели**

**12. Мобильное приложение (PWA)**
- Оффлайн-режим для цеха, сканирование штрихкодов
- Push-уведомления
- **Срок: 2-3 недели**

## Оценка стоимости

| Очередь | Срок | Стоимость (1 разработчик, ~3000 руб/час) |
|---------|------|------------------------------------------|
| **1. Критичные** | 8-12 недель | 960 000 - 1 440 000 ₽ |
| **2. Важные** | 10-14 недель | 1 200 000 - 1 680 000 ₽ |
| **3. Дополнительные** | 8-12 недель | 960 000 - 1 440 000 ₽ |
| **Итого** | **26-38 недель** | **3 120 000 - 4 560 000 ₽** |

При команде из 2 разработчиков сроки сокращаются в ~1.6 раза, стоимость остается.

**Примечание**: EVA не является и не станет полной заменой 1С:ERP. Цель — закрыть производственный контур (MES/MRP + склад + качество + себестоимость), который 1С:ERP покрывает избыточно и дорого. Финансы, бухгалтерия, налоговый учет остаются в 1С.

### С чего начинаем

Рекомендую начать с **Управления качеством (ОТК)**, так как:
- Данные о браке уже частично собираются при выполнении операций
- Не требует сложных интеграций
- Дает немедленную ценность для производства
- Реализуется через новые таблицы + расширение существующих страниц

Технически: создаем миграции для таблиц контроля качества, добавляем контрольные точки в техмаршруты, расширяем диалог выполнения операции полями ОТК.
